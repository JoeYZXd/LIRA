# TypeSafe Jev 缓存语音测试

此功能在开发者控制台顶部，以文本代替 ASR，测试“分段语义判断 → 固定语料选择 → 缓存音频播放”。不会录入、保存、覆盖声纹，也不会自动推进真实录入会话。

## 使用

1. 在设备服务环境设置 `TYPESAFE_API_KEY`，可选设置 `TYPESAFE_MODEL`（默认 `jev-latest`），重启应用。密钥不在网页输入或返回。
2. 登录 `/dev`，点击“预热固定语音”。11 句固定语料通过当前本地 TTS 合成到内存，预热不播放，耗时单独显示。修改语速后需重新预热；重启后缓存清空。
3. 选择模拟阶段，点击“开始文本测试”，输入用户回复。每 450 ms 合并提交当前完整快照；中文输入法组合期间不提交未完成组合。
4. 查看分段记录。预判期间没有播放或声纹写入；新版本取代旧版本，最终内容一致时复用现有判断。
5. 点击“输入完成并播报”作为用户说完的明确标记。最终版本判断完成后只播放一次对应缓存；若失败则不播放。播放走设备原有 TTS 队列、音量、所有者取消与 HAL 输出，不调用浏览器语音。
6. 可随时取消并停止测试播报。单轮 3 分钟有效，最多 100 次文本提交；刷新丢失控制后，服务端期限仍会结束测试。测试期间其他使用 dev_mutex 的设备测试返回忙碌。

## 时间口径

所有核心指标在服务端使用同一单调时钟：

- 输入完成时间：服务端接收并接受最终快照的时间。包含用户点击到设备的上行网络时间不计入该指标。
- 首帧输出：HAL 首次消费本轮非空 PCM 的时间。
- 播放排空：HAL 输出排空事件。
- 响应等待：输入完成 → 首帧输出。
- 播放跨度：首帧输出 → 排空，包括期间可能的停顿，不等于纯语音内容时长。
- 总耗时：输入完成 → 排空。

页面另显示浏览器点击完成至收到完成状态的近似耗时，包含网络和轮询等待。缺失的音频事件显示“—”，不能补成零。HAL 时间不是扬声器声学首声或尾声，实际声音仍需外部录音校准。

分段表记录版本、字符数、相对测试开始的请求时间、决策耗时、选择、模型与置信度（模型名在接口结果中）。过期或取消的判断不能触发播放。置信度供实验观察，不是身份授权依据。

## 实验边界

固定语料有请求确认、重录、取消、继续、改称呼请求、澄清和保存确认测试提示。改称呼只回读请求，不假装已抽取或更改资料；保存提示明确说明没有实际保存。Jev 可选项受模拟阶段限制。

TypeSafe 请求直达官方 `https://api.typesafe.ai/v1/systemone`，使用可复用 HTTP 连接、12 秒请求超时，无自动重试；失败显示错误。输入只保留于当前进程会话，不存日志或数据库。隐私开启时取消决策和测试播放、清除本轮状态；关闭应用时清理任务与连接。

测试源码使用受控服务和音频替身证明状态机与接口行为；这些结果不代表 TypeSafe 在线中文准确率或设备声学延迟。当前开发环境未发现 TYPESAFE_API_KEY，未进行真实在线 Jev 调用或板上播报测量。
