# 教学基础能力运行验证预案

本轮仅本地实现与隔离云端探测，不部署、不重启设备服务、不安装电视 APK。`LIRA_REALTIME_CAPABILITIES` 默认关闭；经典链路保持原状。模型支持门禁和硬件门禁尚未通过，当前不具备开启条件。

以后满足门禁并获得部署授权后，负责部署的人应在首个受控会话和首次实际设备操作期间验证以下信号；仓库没有既有告警指标或值班安排，不虚构数值阈值、线上看板或负责人。

| 核查 | 正常信号 | 失败处理 |
|---|---|---|
| 模型工具结果 | 真实 call/result 对应；pending 不冒充完成；跨轮读取原操作实际业务状态 | 出现无结果、错误完成声明、重复副作用时关闭扩展开关并保留脱敏回执 |
| 暂停、停止和隐私 | 当前约定失效，待执行工作撤销，无后续资料/语音输出 | 任一旧权限仍执行即回退，不靠模型解释补救 |
| 换人 | 旧工具及云端会话关闭，新会话不带旧人物正文或工具结果 | 旧资料可复述或旧操作继续输出即关闭扩展 |
| 静默计时 | 当前有效计时不被 60 秒空闲回收；到期只生成事件 | 意外结束、事件丢失或自行推进均不通过 |
| 摄像头与播放 | 麦克风持续接收；OCR 真正结束才释放锁；物理扬声器排空和打断结果真实 | 阻塞输入、锁不释放或中断后继续播报即回退 |
| 电视 | 探测版本与能力；只有实际 clear 确认才宣称已清屏 | 超时、旧接收器、无确认均报告不可用，不唤醒或自动重试 |
| 数据与管理面 | 家长确认版本才用于标准；未核对记录可见；修改/删除后旧引用无效 | 草稿被当标准、越权写入或遗忘后仍可读取即关闭扩展并排查 |

可使用现有元数据、脱敏工具状态和隔离合成回执；不增加家庭音频、图片、教材全文或秘密偏好的线上日志。诊断时核对当前开关、实际源码摘要、会话 generation/owner、operation_id 和 status。开关关闭只能回到旧注册表，不能替代对已经启动会话的关闭；回退需要确保扩展会话及待处理任务已结束，再使用既有链路。数据库只做已验证的增量迁移，不以删表回滚。

已有设备库备份与重复迁移测试见 [数据兼容回执](2026-10-19-teaching-data-compatibility.json)，当前真实模型失败见 [U10 人工复核](2026-10-19-teaching-capabilities-u10-matrix-review.md)。发布前必须补齐物理麦克风/播放、摄像头 OCR、TV 配对/清屏证据；合成输入和静音 PCM sink 不替代这些证据。
