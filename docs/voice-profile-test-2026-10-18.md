# 声纹档案一句话测试

后台 → 声纹档案 → 某个已建档成员旁“测试”。弹窗说明使用 LIRA 麦克风、会先停止当前语音对话；点击开始录音，自然说 5—10 秒，至少两秒有效语音，再点“说完了，开始比对”。显示是否识别为所选档案、是否实际匹配其他成员、本档案/最高/次高分、生产匹配门槛、分差和拒绝原因。测试完成后释放麦克风，可重新唤醒聊天。

复用 GuidedVoice 的独占租约、生产采集钩子与隐私/40 秒采集上限/输入中断处理，不另外打开声卡。单次测试租约两分钟到期。语音按原能量质量检查裁剪，取最后最多十秒用当前本地模型提取；使用 SpeakerIdentity.match_diagnostics 与同一 top1_with_margin 规则比对完整档案库，使用生产 threshold/margin，不采用录入一致性分数或聊天身份保持规则。不写声纹、姓名、个人记忆或线上识别诊断状态，音频不落盘，不调用云端 ASR/豆包/Jev。

POST /dev/api/voice-test 沿用控制台鉴权，begin 指定已建档 member_id；stop/status/cancel/restart 必须持本次随机 token。拒绝占用其他录入/测试的麦克风租约；begin 错误不返回另一会话 token，且清理只能释放自己拥有的租约。短音、质量拒绝、提取异常、成功、取消均释放自己的采集；隐私开启和到期由复用的 watchdog 清理。页面离开尝试发送 cancel，离线由上限兜底。结果是本次音频的识别诊断，不作准确率承诺。

相关后端 78 项通过，手机/桌面浏览器两项通过：成功/低分、再测、关闭释放、档案未变；后端另覆盖匹配到别人、短音、隐私、超时、占用冲突不清理别人的录入。板端检查只读页面/静态资源与鉴权，不替用户实际录音；真实人声效果由用户点击后直接查看分数。部署仅六个指定运行文件，保留原档案。
