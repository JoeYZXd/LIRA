# 教学管理操作手册

适用：2026-10-22 阶段交付版。面向家长和孩子；产品规则见 [PRD](teaching-prd.md)。

## 1. 进入管理与准备资料（P1）

1. 在家庭局域网打开 [LIRA 设备面板](http://192.168.3.253:8080/dev)，完成家长登录，进入“教学管理 → 语文 → 默写”。也可直接访问设备的 `/dev/dictation`。
2. 在“孩子与教材进度”选择孩子和语文课本，填写实际已学到的单元、课次，点击“保存教材进度”。不同孩子分别保存。
3. 点击“管理课本与核对原文”，检查目标课的原文、二会字、四会字、扩词和背诵要求。缺失或识别有误的资料，先由家长确认、补充或修正后再使用。
4. 电视开机联网并打开 LIRA APP，孩子准备好本子和笔。资料或设备不可用时先处理提示，不重复新建同一任务。

当前设备地址以仓库 `AGENTS.md` 与 `deploy/SETUP.md` 为准；历史验收里的旧地址不作为当前入口。

## 2. 发起并发送默写（P2）

1. 在“准备默写”的“任务或回复”输入“默写第8课”，点击“发送给大模型”。也可通过已配置的语音对话发起，并明确孩子与范围。
2. 模型如询问教材、范围或缺失资料，在同一准备会话回复。没有必要解释作业布置原因。
3. 如页面出现“确认采用这些候选词”，先检查候选，再确认。模型建议不是教材事实。
4. 准备成功后，在“任务与实际执行”选择该任务；家长可展开“任务全文、版本与选词理由”检查内容。该区域含答案，不向孩子展示。
5. 点击“发送／重试发送”。以“实际回执”和电视状态确认到达，发送已接受不等于已显示或已开始。电视准备页由孩子按右键开始认读。

发送失败时先刷新实际回执，再对同一任务重试发送；不要反复新建准备会话。只有打算生成一份新任务时才点击“新建准备会话”。单次任务结束后不自动再开始。

## 3. 孩子怎样操作电视（P3、P4）

二会字显示组词，整词放大，每屏容量自动适配。电视没有上滑、下滑操作。

| 遥控器 | 二会字认读 | 四会词语默写 |
| --- | --- | --- |
| 左键 | 上一屏 | 上一词并播放；首词不回绕 |
| 右键 | 开始／下一屏 | 下一词并播放；最后一词写完后按右键结束 |
| 确认键 | 无操作 | 重播当前词 |
| 返回键 | 暂停 | 暂停 |
| 暂停后继续 | 右键 | 确认键 |
| 长按返回键 | 结束练习 | 结束练习 |
| 上、下、功能键 | 无本功能额外操作 | 无本功能额外操作 |

每个四会词只播报一次，播报结束停住，孩子写好后再按右键。页面显示“第几个词”“一共几个词”和圆点，不显示词语答案。听不清按确认键，想回到上一个按左键。

## 4. 提问、暂停与恢复（P5）

孩子可以在对话中问“刚才是什么词”“这个词是什么意思”等。系统先请求电视暂停，实际暂停成功后模型才解释；解释播放完毕会询问是否继续。孩子确认继续后恢复当前项目，被打断的播报会重播。

如果提示暂停失败或电视断开，先恢复连接，不同时手动推进和要求模型解释。断线或重启恢复后先确认当前项目，再按页面提示继续；不会从断开位置突然发声。

## 5. 上传照片、记错词与查看历史（P6）

1. 练习结束，在管理页选择孩子和对应任务，进入“纸面照片与家长核对”。
2. 上传一张或多张 PNG/JPEG 照片，每张最大 10 MiB。初版保存照片，不自动 OCR、不自动打分。
3. 选择“尚未核对”“已核对，有错误”或“已核对，全部正确”。如有错误，勾选错误词语，必要时记录错字；认读困难在“认读困难的二会字”单独记录，可补充备注。
4. 点击“保存核对结果”。发现误记可再次修正保存；下次模型准备任务会读取最新有效结果及相关历史。
5. 在“学习事实查询”填写单元、课次，读取孩子本课知识记录。只上传照片而未核对的任务仍是未核对，不能视为全对。

没有真实作答的演示任务请保留“尚未核对”，备注演示，不填写全对。页面等待耗时不是纯书写速度。

## 6. 调整流程、播报与业务 skill（P7）

在“可配置流程”选择阶段及顺序，可仅认读、仅默写或两者组合。当前建议保留“先认读，再默写”和“遥控手动播报”。手动模式每词只播放一次，次数与间隔不应被理解为自动切到下一词。

豆包当前采用参数：

| 表单项 | 建议保留值 |
| --- | --- |
| 默写语音合成 | 豆包语音合成 2.0 |
| 资源编号 | `seed-tts-2.0` |
| 音色编号 | `zh_female_vv_uranus_bigtts`（Vivi 2.0） |
| 音调、豆包语速、音量 | `0`、`-20`、`30` |
| 语音指令 | `朗读 播音 拉长音 着重强调 标准普通话` |

“本地合成语速”是历史本地合成配置，不替代“豆包语速”。TTS 表单不改变 KIMI 调度模型；模型仍使用后台已有模型配置。保存“流程新版本”后，需新建准备会话才能采用，已生成任务不变。

在“默写业务 skill”调整教学规则并保存新版本。应保留读取孩子历史、优先错词、注意前后鼻音与难写字等规则；skill 改教学判断，不能代替代码增加遥控功能或改变状态机。更新同样只影响新准备会话。

若提示“版本已更新”，当前编辑会保留。点击“读取最新版本号，保留当前编辑”，比较最新内容后合并再保存，不覆盖其他家长刚保存的修改。

## 7. 查看执行与开关电视日志（P8）

在任务详情点“刷新实际回执”，展开“实际事件日志”查看收到任务、当前项目、播放完成、暂停和结束等事实。管理按钮可暂停、继续、重播、上一词或下一词，测试时避免与实体遥控同时操作。

在“电视调试显示”勾选或取消“在电视上显示调试日志”，点击“保存电视调试设置”。通常保持关闭；排障时临时打开，结束后关闭。此设置对当前电视实时同步，不需要重新生成任务。电视离线时会提示待同步，连接后再确认。关闭只隐藏电视上的日志，后台执行日志继续保留。

## 8. 常见处理

| 现象 | 操作 |
| --- | --- |
| 电视没收到 | 确认开机联网、LIRA 在前台，刷新实际回执，重试发送同一任务 |
| 播报后不继续 | 手动模式的正常行为；写好按右键，重听按确认键 |
| 认读确认键没反应 | 正常；用左右键翻屏 |
| 没声音或声音不完整 | 检查电视音量与静音，确认当前是四会阶段；打开调试显示并记下任务、项目、时间，交给维护者，不连续跳词覆盖现场 |
| 配置改了但任务没变 | 旧任务绑定旧版本；新建准备会话生成新任务 |
| 学习记录没有正确率 | 先完成家长核对；初版不会凭照片、完成事件或等待耗时自动评分 |

开发与维护者排障方法、日志证据边界见 [开发复盘](teaching-retrospective-20261022.md)。
