# 两条语音交互路径试验

开发者控制台 → 左侧「运行参数」→「语音交互路径 · A/B 试验」。

- A：现有本地 ASR、对话路由/大模型、TTS。TypeSafe Jev 的缓存语料选择试验仍在「Jev 测试」中独立运行，尚未成为生产语音主链路的一环。
- B：豆包实时语音 3.0 全双工。板子上传 16 kHz PCM，接收 24 kHz PCM 并直接播放，不经过本地 ASR、大模型和 TTS 合成。

## 切换与使用

选择路径并点击「切换并结束当前对话」。切换停止旧播报/会话、清理识别缓冲和未完成录入，保留已经保存的声纹。模式保存至设备库 meta 的 `conversation_path`，服务重启后保留。

B 模式待机只在本地检测唤醒，不建立云端会话、不上传音频。可以唤醒设备，也可以点击「开始豆包语音试验」。等待连接成功提示音后说话；连接中不缓存或补传提前说的话。会话开始后持续上传音频以支持全双工交互。连续 60 秒无识别/回复活动后结束，之后可再次唤醒。本地播报及尾音保护期间刷新活动计时；正式语音路径没有本地 3 分钟硬上限（控制台文字转语音试验的独立限制不变）。

点击「结束当前语音会话」、开启隐私、麦克风独占测试、输入中断、切换路径或退出服务均关闭云端会话并停止云端播放。连接失败会显示失败，模式仍为 B，不会暗中回退 A。Jev 与本地 TTS 测试需切回 A。

## 豆包配置

板子文件：`/home/orangepi/.config/lira-doubao-realtime.env`，属主 orangepi、权限 600。

```dotenv
LIRA_DOUBAO_REALTIME_API_KEY=填写已开通实时语音服务的APIKey
LIRA_DOUBAO_REALTIME_VOICE=zh_female_vv_jupiter_bigtts
```

示例音色来自官方全双工接口示例。可改为控制台中适用于实时语音服务的音色。TTS 与实时语音是不同服务，不应仅凭 TTS 可用就认定实时语音权限已开通。

加载文件的 user service drop-in：`/home/orangepi/.config/systemd/user/lira.service.d/60-doubao-realtime.conf`。

```ini
[Service]
EnvironmentFile=-/home/orangepi/.config/lira-doubao-realtime.env
```

填好后执行 `systemctl --user restart lira`。只有修改 drop-in 本身时才需要先执行 `systemctl --user daemon-reload`。不要把密钥发到聊天、提交仓库或写进页面输入。

## 工具与声纹

2026-10-17 更新：B 提供设备状态、结束对话、六个红外工具，八个声纹录入工具，以及当前说话者身份查询工具。工具参数做白名单校验，同一个 `call_id` 不重复执行。工具被拒绝或不可用时不会触发本地后续动作。

声纹录入不再关闭豆包连接或切换本地 ASR：豆包通过 `start_voice_enrollment`、`set_voice_enrollment_details`、`start_voice_sample`、`check_voice_sample`、`get_voice_enrollment_status`、`save_voice_enrollment`、`cancel_voice_enrollment`、`reset_voice_samples` 完成引导与调用。资料解析由豆包完成，本地复用声纹质量门、说话人特征提取器和现有原子保存接口；未新建声纹库。成功或取消后继续原豆包会话。

同一份经回声保护的用户音频同时供豆包和本地采集，播报和尾音期间不采集。采集达标后核对姓名称呼，再等待本人新的明确确认语音；确认语音须与所采集声纹一致。本轮可重录或修改未保存资料，不覆盖已经注册的同名/同声纹成员。当前身份已在自然聊天中异步累计和匹配，匹配后通过session.update带入豆包上下文；身份提问读取本地会话缓存，不要求朗读测试句。约10秒仍未匹配时停止反复查档，仅在身份询问时邀请自愿录入；明显换人证据重置身份。详见doubao-passive-identity-2026-10-17.md。日常个人长期记忆的自动读写仍未接入。详见 `doubao-voice-enrollment-tools-2026-10-17.md`。

## 观察与计时

- 路径面板展示真实选择、配置是否齐全、连接/失败/本地录入状态。
- 实时交互事件中记录豆包识别完成文字、回复完成文字及连接/工具事件，仅走现有内存展示遥测。
- B 本轮耗时起点为客户端收到云端转写完成事件，终点为 HAL 消费首帧或播放排空。因此不含用户实际停止说话到云端判停事件抵达的时间，不能视作声学端到端延迟。
- A 的 ASR/LLM/TTS 指标和 Jev 文本缓存测试保持原有口径；与 B 比较时需明确起点。
- 密钥与声纹向量不发送到后台状态接口或豆包工具返回。B 模式录入期间的用户音频仍会发送给豆包用于语音交互；本地另行提取特征，不调用本地 ASR 或原有文字大模型进行资料解析。临时原始音频不写磁盘，取消、退出或隐私模式清除本轮缓存。
