# 豆包对话实验室

已于 2026-10-16 部署到开发板。入口：开发者控制台左侧「豆包对话」。

## 使用与反馈

1. 点击「开始对话」，输入文字并发送。板子将文字合成为语音，发送给豆包实时语音服务；同一连接保留多轮上下文。
2. 每轮展示输入原文、实际识别结果、回复、工具调用和耗时，可手动试听回复音频。不会自动在板子上播放。
3. 展开「这一轮有什么问题？」，选择问题类型，填写问题和期望回复。反馈自动保存；导出前会等待反馈保存完成。
4. 导出 Markdown 方便阅读，JSON 方便分析，ZIP 包含两种记录和仍在缓存中的回复 WAV。将文件发给开发者，并注明需要重点检查的轮次。

工具调用在实验室中模拟执行，不会真正录入声纹或修改设备资料。结束对话保留记录；重新连接开启新的模型上下文。测试期间独占设备交互，其他音频测试须先结束。

记录只保存在设备内存中，刷新页面仍可读取；主动清空、开启隐私模式或重启服务会删除。重要记录请及时导出。当前限制为 20 轮、每轮输入 200 字、连接最长 180 秒、空闲 45 秒断开。回复音频总缓存 8 MiB，超过后先移除旧音频，文字与反馈保留。

耗时是合成测试链路的统计，包含本地输入语音生成和发送，不代表真人停止说话后的纯响应延时；回复音频时长也不等于实际扬声器播放完成时间。
