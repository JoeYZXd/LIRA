# 1080px 教学卡片与课本工作区

教学管理卡片最大 1080px，较窄屏幕自适应。课本入口先展示书形圆角卡片和导入按钮；封面图片或名称位于书形内部，删除重复的标题和说明段落。

点击课本后在原卡片内显示四个页签：核对结果、课本信息、课本书页、课文。页签有 tab/tabpanel 语义和方向键导航，切换保留编辑。结果可定位课文，信息页编辑名称及封面，书页页签可访问全部导入页、翻页、设置当前页为封面及关联单元/多课次；课文页按单元/课次编辑标题、四会字、二会字、扩词和选填背诵内容。

封面规则：新导入记录默认第一张导入页；没有历史选择字段的旧记录在读取时兼容默认第一页，不批量改写文件；明确设置无封面的仍显示书名。已发布课本可单独补设/清空封面，只有导入源的 cover_page 和 revision 改变，已发布教材 JSON 字节不变。字表、正文和页课关联仍由修订草稿编辑。页面单元存于 pages[].unit，页课关联存于 lessons[].source_pages，修订时保留。
