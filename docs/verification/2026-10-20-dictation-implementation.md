# 默写能力实现与验证（2026-10-20）

## 范围与约束

按本次用户确认的真实默写交互实现：先确认电视、尝试第7课准备画面、等待画面反馈，再选语文教材及已核对课次；四会字语音三遍后等孩子指示，二会字每页最多8个拼音后等孩子指示。电视不可达允许失败，但不能省略发起动作或谎报成功。由豆包选择工具和自然询问，工具不自动切题、计时或串行运行整套教学流程。

仅扩展已有豆包实时链路的默认工具；经典链路不变，LIRA_REALTIME_CAPABILITIES 保持 false，其他未验收扩展不开放。本次不自动修改家庭课本、不自动核对或发布、不生成假电视回执。

## 已实现

- TextbookPractice.available_books / prepare：只读已发布教材和导入草稿。目录逐课给出 reviewed；指定课次已核对即可练习，其他课次可继续待核对；未核对或撤回核对后不提供答案。没有把草稿全量发布。重复课号仍要求单元，单本教材无需模型抄写长编号。
- 新增 check_dictation_tv、show_dictation_ready：先实际探测接收端；收到用户电视已开的回答后尝试发送准备画面，区分 displaying、displayed 和 failed，并询问画面是否可见。网络失败不是电视关机证明。
- 新增 get_dictation_material：只读取语文教材中的已核对课次。多本选择需观察到模型报书名询问、下一轮真实用户同意；有确认身份时可读取和保存该说话人的上次课本选择，无确认身份不读取个人偏好。新导入记录 imported_at，旧数据使用导入目录/文件时间作为近似。遗忘会清除对应偏好。
- 新增 present_dictation_item：four 复用现有实时精确语音插入能力，每字三遍；只有输出排空才 completed。two 生成最多8项带声调拼音，按独立同意发送电视。材料变化、核对撤回、过期材料和重复调用均检查；相同教材重复读取复用材料标识，不能借换标识绕过等待。
- 进度由真实用户指示推进，也支持“要显示下一页吗？”→“好的”的协商；否定和无新指示不能自动推进。四会字多音字确认读音提示后播报，二会字多音字确认候选拼音后展示，不能悄悄选读音。
- cancel_dictation 取消本任务语音与仍在发送的电视操作；不宣称已传出的电视内容已撤回。关闭会话和身份变化清除任务材料。默认工具结果及后续文本回显按既有教学敏感内容规则最小化保存。
- 教材页面提示改为“本课核对并保存即可默写”，整本发布入口保留；卡片布局、书架和其他界面行为未变。
