# 语音退出、勿扰与控制机制

## Summary

为 LIRA 增加一组语音退出与控制机制：扩充退出词表使会话可被自然口语立即结束；任何播报中可喊停；新增手动进出的勿扰模式（含三次重复逃生舱）；「唤醒词+特定短语」真关机；另补「再说一遍」、全局音量、状态自查三个高频交互。全部走本地封闭词表与意图等价匹配，不经云端。

---

## Problem Frame

现状下，让 LIRA「安静下来」几乎是场拔河。会话退出只有两条路：精确说出「取消/算了」，或干等 8~30 秒超时。低视力老人措辞稍有不同——「行了」「别念了」「闭嘴」——就落入「识别失败引导」循环，设备反复出声追问，与「想让它安静」的意图正相反。朗读/播报中更窄：只有 6 个白名单词有效，喊「别念了」毫无反应。想彻底安静（午休、看电视怕误唤醒）没有语音手段——隐私模式只能子女在 Web 上开。

「关机」一词则卡在另一处：老人说「关机」多指关电视（电视遥控器上就叫关机），现有词表把这类话当未知指令；而真正「让设备歇着」反而无词可用。

成本形态：设备的「不响应」被老人体验为「不听话 / 坏了」，每一次想停都要对抗超时或引导循环，侵蚀对设备的基本信任；子女也只能等老人放弃。

---

## Actors

- A1. 老人用户（低视力）：语音交互的直接使用者；退出、打断、勿扰、关机机制的服务对象。
- A2. 子女/管理者：通过管理后台与电话远程协助排障；状态自查功能的主要间接受益者（电话里让老人问一句即可定位故障）。

---

## Key Flows

- F1. 勿扰模式全周期
  - **Trigger:** 老人说「唤醒词+进入勿扰模式」（会话中可直接说「进入勿扰模式」）。
  - **Actors:** A1
  - **Steps:**
    1. 当前会话立即静音结束，进入勿扰：继续听，但一切语音反馈静默（裸唤醒词也不提示）。
    2. 勿扰中正常指令被忽略不出声，但被计数：同一意思（同一设备+同一动作）连续 3 次 → 主动开口问「当前在勿扰模式，是否退出？」。
    3. 同意 → 退出勿扰，追问「是否执行刚才的指令」，确认后执行；拒绝退出 → 继续勿扰沉默。
    4. 任意时刻说「唤醒词+退出勿扰模式」直接退出；说「唤醒词+你现在是在勿扰模式吗」获语音状态回答（勿扰内外皆可问）。
  - **Outcome:** 老人可独立进出勿扰，且不存在「被困在勿扰里」的路径——退出短语、状态查询、三次逃生舱三个口子都能出声。
  - **Covered by:** R8, R9, R10, R11, R12, R13, R14

- F2. 播报打断
  - **Trigger:** LIRA 任何出声时刻（朗读中、回答播报中），老人喊「别念了 / 行了行了 / 停」等。
  - **Actors:** A1
  - **Steps:** 本地关键词通道命中喊停说法 → 立即停止播报 → 回待机。
  - **Outcome:** 播报即刻安静，无需等读完或记白名单词。
  - **失败路径:** 喊停未被命中 → 播报继续，老人仍可用唤醒词硬打断或等自然结束。
  - **Covered by:** R6, R7

- F3. 真关机
  - **Trigger:** 老人说「唤醒词+立即去休息」。
  - **Actors:** A1
  - **Steps:** 播一句告别语 → 系统关机。
  - **Outcome:** 设备彻底安静；重新开机靠物理电源键，开机后为正常模式。
  - **Covered by:** R4

## Requirements

**退出与结束会话**

- R1. 会话中任何状态，识别退出说法（「退出 / 别吵我 / 行了 / 闭嘴 / 别念了 / 够了」等封闭词表）即立即停止当前播报与动作，结束会话回待机，不等超时。
- R2. 退出与喊停说法的匹配采用封闭候选集内的容错匹配（不要求老人精确措辞），不做开放式 LLM 语义判断。
- R3. 待机态不监听退出说法；待机仅响应唤醒词（含唤醒词组合指令）。

**真关机**

- R4. 「唤醒词 + 立即去休息」→ 播一句告别语后执行系统关机；不加语音二次确认；重新开机靠物理电源键。
- R5. 除 R4 特定短语外，任何含「关机」的话都不构成关闭 LIRA：会话语境按结束会话处理，家电语境按家电指令处理。

**播报打断**

- R6. LIRA 任何出声时刻（朗读中、回答播报中）识别喊停说法（「别念了 / 行了行了 / 停」等）即立即停止播报并回待机；打断检测走本地关键词通道，不得复发 TTS 回声自说自话问题。
- R7. 播报打断一律回待机、不进聆听；「暂停 / 继续」语义仅保留在朗读白名单内。

**勿扰模式**

- R8. 「唤醒词 + 进入勿扰模式」进入勿扰：当前会话立即静音结束；此后语音识别保持运行，但一切语音反馈静默，含裸唤醒词不提示不应答。
- R9. 勿扰中正常指令默认忽略且不出声；勿扰中一切语音仅本地处理，不上云。
- R10. 三次逃生舱：同一意思的指令在勿扰中连续出现 3 次（换说法但同一设备+同一动作算同义）→ LIRA 主动开口询问「当前在勿扰模式，是否退出？」；同意 → 退出勿扰并追问「是否执行刚才的指令」，确认后执行；拒绝退出 → 继续勿扰；同意退出但拒绝执行 → 维持退出、不执行。中途出现不同指令则计数清零；进入勿扰时计数清零。
- R11. 「唤醒词 + 退出勿扰模式」→ 退出勿扰，恢复正常交互。
- R12. 「唤醒词 + 你现在是在勿扰模式吗」（同义问法模糊匹配）→ 无论当前是否勿扰，都语音回答当前状态。
- R13. 勿扰三短语（进入/退出/询问）在会话中不带唤醒词直接说也生效；待机中必须带唤醒词。
- R14. 勿扰状态不持久化：设备重启后为正常模式。

**补充交互机制**

- R15. 回答播完后的追问窗口内，「再说一遍 / 没听清」→ 原文重复上一条回答，不重新生成；朗读中「再读一遍」维持现状。
- R16. 「声音大点 / 小点」在任何会话态可用，全局生效并持久化（重启保留）。
- R17. 「你连上网了吗」等状态自查 → 播报网络、云端、麦克风（隐私）状态，措辞用老人能懂的话。

## Acceptance Examples

- AE1. **Covers R1.** Given 聆听中已触发一次识别失败引导，when 老人说「行了，别吵我」，then 立即结束会话回待机，不再继续引导重试。
- AE2. **Covers R6, R7.** Given 朗读进行中，when 老人喊「别念了」，then 朗读立即停止并回待机；不进入聆听，无需说白名单词「停止」。
- AE3. **Covers R4.** Given 待机态，when 老人说「小立，立即去休息」，then 播一句告别语后系统关机；重新上电后为正常模式。
- AE4. **Covers R5.** Given 会话中，when 老人说「关电视」，then 按家电指令执行（高危设备走既有确认流程），绝不论为关闭 LIRA。
- AE5. **Covers R8, R9.** Given 勿扰中，when 老人说「小立」或「小立，开电视」，then 无提示音、不应答、不执行；后者计入逃生舱计数。
- AE6. **Covers R10.** Given 勿扰中老人已连续两次表达开电视，when 第三次换说法再说同一意思（如「看电视」），then LIRA 主动问「当前在勿扰模式，是否退出？」；老人答「是」→ 退出勿扰并追问「是否执行刚才的开电视」；答「开吧」→ 执行开电视。
- AE7. **Covers R10.** Given 逃生舱询问中，when 老人答「不用」，then 继续勿扰沉默，不执行指令。
- AE8. **Covers R12.** Given 正常模式（非勿扰），when 老人说「小立，你是不是睡觉着呢」，then 语音回答当前不在勿扰模式。
- AE9. **Covers R14.** Given 勿扰中设备被断电重启，when 重启完成，then 设备为正常模式，唤醒词正常应答。
- AE10. **Covers R15.** Given 回答播完后的追问窗口，when 老人说「没听清，再说一遍」，then 原文重复上一条回答，不重新生成、不计新指令。
- AE11. **Covers R16.** Given 任意会话态，when 老人说「声音小点」，then 立即以更低音量播报后续内容，重启后仍生效。

## Success Criteria

- 老人在「想让它停 / 安静 / 关掉」的任一时刻，都能用一句自然口语让 LIRA 立即照做，不再需要等超时、背精确指令词或求助子女。
- 勿扰模式可被老人独立进出，且不存在「困在勿扰里」的路径（三次逃生舱兜底）。
- 新增常驻听词/识别通道后，既有 TTS 回声自说自话防护不回归（回归测试覆盖）。
- ce-plan 能从本文件直接推导状态机改动点与词表，无需再发明产品行为、范围边界或成功标准。

---

## Scope Boundaries

- 定时勿扰 / 自动恢复——已否决，勿扰只手动进出。
- 「别吵我」作为勿扰入口——维持 = 结束会话，勿扰入口只用显式短语。
- 语音开机——硬件路径不存在，关机后靠物理电源键。
- 退出 / 勿扰 / 喊停说法的后台可配置化——先本地固定词表，真实使用后再评估。
- LLM 开放式「用户想退出 / 想勿扰」意图判断——保持封闭词表 + 本地意图等价。
- 家电控制语义变更——「关电视 / 关机」等家电指令行为保持现状。

---

## Key Decisions

- 真关机用特定短语（唤醒词+「立即去休息」）而非「关机」：避开家电「关机」歧义与误触发；短语日常对话说不出来，误触趋近于零。
- 退出/喊停/勿扰全部走本地封闭词表 + 拼音/意图等价容错：本地优先、低延迟、fail-closed，不引入云端语义判断。
- 播报打断经常驻本地关键词通道而非重开播报中 ASR：不复发 TTS 回声自说自话问题（保护既有修复）。
- 勿扰三次逃生舱：把「老人被无视后不断重复」这一自然行为转化为退出信号，解决「不知道退出短语而被困勿扰」。
- 勿扰不持久化：重启即恢复正常，避免「设备是哑巴」的远程排障困难。
- 退出/打断后回待机不进聆听：与「一次唤醒=一条指令」的会话模型一致，避免「喊停反而被追问」。

---

## Dependencies / Assumptions

- 现有对话状态机与三路音频路由（唤醒/聆听/播放白名单）是改动基座；播报打断需要一路常驻本地关键词检测（扩展现有 KWS 通道或新增），可行性由 planning 验证。
- 勿扰中识别常开的算力开销（板载 NPU/CPU）由 planning 评估；若不可行需回本文件修订逃生舱设计（如降级为仅唤醒前缀计数）。
- 「相同意思」的本地等价判定覆盖本地规则层可解析的指令（设备+动作归一）；LLM 层指令在勿扰中因不上云约束无法本地判等，不计入逃生舱计数。
- 唤醒词、朗读白名单词与新增喊停/勿扰短语之间的冲突消解（如「停」一字词的误触发面）由 planning 处理。
