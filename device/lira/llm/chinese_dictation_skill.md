# 语文认读与默写业务指引

严格围绕发起者指定的孩子、教材和课次准备任务；范围不明时向原发起渠道澄清，不追问布置原因。教材缺失或修改须由家长确认保存，模型候选不能替代家长确认。

结合该孩子相关课次的学习事实、最新有效核对、历史错词错字、认读困难与辅导记录判断选词。优先关注尚未掌握词、前后鼻音易混字和难写字，说明依据；不能凭标签或固定掌握阈值判断。未核对、练习完成、翻页、上传照片都不是答对或掌握证据，不另起自动评估。

默认二会字以组词展示认读及四会字扩词默写；二会字提交 recognition_words 数组，每词至少二字，覆盖全部二会字，优先教材组词，缺词向发起者确认；词语覆盖范围内全部四会字，优先教材或维护词库，不重复增加单字。明确要求单字时才增加单字环节。缺词提出候选并向发起者确认。保存目标字覆盖和选词理由，沿用准备会话绑定的 skill 与流程版本。背诵要求仅作教材资料，本版不执行背诵；不在执行中换词或增词。

电视执行固定任务：认读使用左键上一屏、右键下一屏，确认键不操作，默写播报完等待孩子说写好了或遥控确认；超时只提醒，不自动跳项。播报完成不等于作答完成。字号、排版和分页交由电视适配。

孩子执行中提问时，先调用暂停工具，收到当前任务和项目的电视实际已暂停回执后才回答，不能把发送成功、accepted 或口头说明当暂停。暂停失败或未知时明确提示，不先解释。可解释字词、词义、组词和例句，并记录本项辅导。回答后询问是否继续；孩子真实确认并且设备回答播放排空后才请求恢复。恢复保留当前项，被打断的播报重新播放；离线或重启先暂停待确认，不突然播放。

不推算未经核对的正确率，不把等待耗时当纯书写速度。家长核对和照片操作属于管理服务，不得由模型冒充提交。

当绑定流程的 manual_navigation=true 时，四会词每次只播报一次，结束后保持当前词等待遥控操作：左键返回上一词并播放，右键下一词并播放，确认键重播当前词。首词左键重播首词，末词右键结束；不循环、不计时重播或自动跳词。模型不能自行推进；收到孩子明确“下一个／写好了”才调用确认下一项，重播或上一词也须有对应请求。认读仅用左右键翻屏、右键开始或从暂停恢复；四会字暂停后的确认键恢复当前词，不能绕过提问解释的暂停与继续确认。
